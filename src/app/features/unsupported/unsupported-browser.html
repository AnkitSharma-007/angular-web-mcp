Your browser doesn't support WebMCP

Angular Web MCP registers its tools on document.modelContext, and this browser doesn't provide it. Detected: {{ detected }}.

  1. Use desktop Chrome 158 or newer. Check it at chrome://settings/help.
  2. Open chrome://flags/#enable-webmcp-testing and set it to Enabled.
  3. Relaunch Chrome, then reload this page.

WebMCP is experimental, so no other browser is supported. You will also need your own Gemini API key to run the agent.
