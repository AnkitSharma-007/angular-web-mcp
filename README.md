# Angular Web MCP

[![CI](https://github.com/AnkitSharma-007/angular-web-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/AnkitSharma-007/angular-web-mcp/actions/workflows/ci.yml)

A Sales & Deals CRM that exposes its Signal state and Signal Forms to AI agents through Angular's native WebMCP APIs.

Built with Angular 22 (zoneless), Angular Material 3, Tailwind CSS, NgRx SignalStore and Google Gemini.

## Development

```bash
npm ci
npm start
npm run lint
npm run test:coverage
npm run build
```

See [docs/architecture-blueprint.md](docs/architecture-blueprint.md) for the architecture and roadmap.
